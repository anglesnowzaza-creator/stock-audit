      2. สแกนนับสต๊อก
      3. ผลการสแกนและความหมาย
      4. ปิดการนับรายคัน

      1 เริ่มต้นใช้งาน

      1. เปิดลิงก์ระบบ จากกลุ่ม LINE (ลิงก์ลงท้าย ?openExternalBrowser=1 จะเปิดใน Chrome / Safari อัตโนมัติ ใช้กล้องสดได้)
        -
      2. เข้าสู่ระบบ ด้วย Username (หรืออีเมล) และ PIN ที่ได้รับจากผู้ดูแลระบบ
      3. ปรับขนาดตัวอักษร ได้ที่เมนูผู้ใช้มุมขวาบน → เล็ก / กลาง / ใหญ่ (จำแยกแต่ละเครื่อง)
      4. ส่งลิงก์ให้ทีม เมนูผู้ใช้มุมขวาบน → คัดลอกลิงก์สำหรับส่ง LINE
      ใส่ PIN ผิด 5 ครั้ง ระบบจะล็อก 10 นาที · ไม่ได้ใช้งานเกิน 6 ชั่วโมงต้องเข้าสู่ระบบใหม่ (รายการที่รอส่งไม่หาย)

      2 สแกนนับสต๊อก

      1. เลือกเป้าหมายการตรวจนับ พิมพ์ค้นหาทะเบียนรถ / ชื่อ / รหัสพนักงาน แล้วเลือกคันที่จะนับ พนักงานที่ไม่มีทะเบียนรถ จะแสดงเป็นรหัสพนักงานแทน · ทะเบียนที่ไม่มีในระบบ พิมพ์แล้วเลือก ＋ เพิ่มทะเบียนรถใหม่
      2. กด “เปิดกล้องสแกน” แล้วอนุญาตการใช้กล้อง ส่องบาร์โค้ด / QR ให้อยู่ในกรอบ ห่างประมาณ 10–20 ซม. สแกนต่อเนื่องได้เลย (มีเสียงปี๊บ + สั่น) ไฟฉาย สำหรับที่มืด (ถ้ามือถือรองรับ) · ถ่ายภาพ ใช้เมื่อเปิดกล้องสดไม่ได้ · ถือค้างที่ code เดิมจะไม่นับซ้ำ
      3. ใช้ปืนยิงบาร์โค้ด (Bluetooth) เปิด “โหมดปืนยิง” แล้วยิงได้ทันที หรือ พิมพ์ SN เอง ในช่องกรอกแล้วกดตรวจสอบ
      4. ติดตามความคืบหน้า ตัวเลข นับแล้ว / ทั้งหมด และรายการที่ยังไม่พบของคันนี้ แสดงใต้ช่องเลือกเป้าหมาย
      5. บันทึกอุปกรณ์ติดตั้ง (สว่าน ฯลฯ ที่ไม่มีในไฟล์ Onhand) กดปุ่ม “บันทึกอุปกรณ์ติดตั้ง” → ใส่ SN และชื่ออุปกรณ์
      สัญญาณหลุด? สแกนต่อได้เลย ระบบเก็บรายการไว้ในเครื่อง (ป้ายสีเหลือง ☁️ ที่ Header) และส่งให้เองเมื่อกลับมาออนไลน์
      สแกนผิด? ยกเลิกได้ที่ “ประวัติการสแกนของฉัน” ในหน้าสแกน (ยกเลิกได้เฉพาะรายการของตัวเอง / Admin ยกเลิกได้ทุกรายการ)

      3 ผลการสแกนและความหมาย

      ผลที่เห็นบนจอความหมายสิ่งที่ต้องทำ
      นับแล้วการ์ดเขียว + เสียงปี๊บSN อยู่ในไฟล์ Onhand และตรงกับคันที่กำลังนับสแกนชิ้นต่อไปได้เลย
      พบต่างหน่วย (ยืม)หน้าต่างสีส้มSN เป็นของคันอื่น แต่มาพบที่คันนี้ ระบบเขียนหมายเหตุ “คัน B ยืมจาก A” ให้อัตโนมัติตรวจ / แก้หมายเหตุ แล้วกดยืนยัน (ไม่ถือว่าของหาย)
      สแกนซ้ำเสียง ตื๊ด ตื๊ดSN นี้ถูกนับไปแล้ว ระบบแจ้งเวลาและผู้สแกนไม่ต้องทำอะไร ระบบไม่บันทึกซ้ำ
      ไม่มีใน Onhandฟอร์มสีม่วงSN ไม่อยู่ในไฟล์ Onhandเลือก สต๊อกเกิน (เครื่องกรอง / สารกรอง) หรือ อุปกรณ์ติดตั้ง แล้วบันทึก

      4 ปิดการนับรายคัน

      เมื่อนับคันใดเสร็จ ให้ ปิดการนับ เพื่อสรุปยอดของคันนั้น (นับครบทุกรายการ ระบบจะถามให้ปิดอัตโนมัติ) หรือกดปุ่ม ปิดการนับคันนี้ ในหน้าสแกน / ปุ่ม ใน Dashboard ได้ทุกเมื่อ

      ไม่พบ

      ตรวจนับคันนี้แล้ว แต่หาของบางรายการไม่เจอ

      นับรวมเป็น “ของหาย” ใน Dashboard
      ไม่ได้นับ (ระบุเหตุผล)

      ไม่ได้ตรวจนับคันนี้ เลือกเหตุผล: พนักงานลาออก · รถซ่อม · พนักงานลางาน · โอนย้ายหน่วยงาน หรือ อื่นๆ (ระบุ)

      ไม่นับเป็นของหาย · เหตุผลบันทึกลงหมายเหตุทุกรายการ
      • คันที่ปิดแล้วจะไม่แสดงในช่องเลือกเป้าหมาย
      • ถ้าภายหลังเจอ SN ของคันที่ปิดแล้ว สแกนได้ตามปกติ (บันทึกเป็นการยืม / พบภายหลัง)
      • ต้องการนับใหม่ กด เปิดใหม่ ที่ Dashboard (Admin หรือผู้ที่ปิดคันนั้น) — รายการ “ไม่พบ / ไม่ได้นับ” จะกลับเป็น “ยังไม่นับ”

      5 รายงานการตรวจนับ / ลงนาม

      1. เปิดรายงาน หลังปิดการนับ ระบบถามให้เปิดรายงานทันที หรือกดปุ่ม ใน Dashboard / ปุ่ม “รายงาน / ลงนาม คันที่ปิดการนับแล้ว” ในหน้าสแกน
      2. ให้พนักงานหน่วยรถลงนามรับทราบ เซ็นชื่อบนจอ ติ๊กยืนยัน แล้วกดบันทึกลายเซ็น
      3. พิมพ์ / ดาวน์โหลด PDF จากแถบเครื่องมือด้านบนของรายงาน (ขนาด A4)
      รายงานแสดง Onhand / จำนวนนับได้ / ผลต่าง แยกเครื่องกรอง–สารกรอง พร้อมหมายเหตุ (ยืม, สต๊อกเกิน, ไม่พบ, ไม่ได้นับ) · ถ้าเปิดคันกลับมานับใหม่ ลายเซ็นเดิมจะถูกล้าง

      6 Dashboard ภาพรวม

      การ์ด KPIภาพรวม / เครื่องกรอง / สารกรอง: ยอด Onhand, นับพบ, ยืมข้ามคัน, ยังไม่นับ, ไม่พบ, ไม่ได้นับ, สต๊อกเกิน
      สถานะพนักงาน / หน่วยรถพนักงานทั้งหมด · เข้ารับการตรวจนับแล้ว · ยังไม่ปิด · แยกตามเหตุผลที่ไม่ได้นับ (คน / หน่วยรถ)
      ความคืบหน้ารายคันกรองคันที่ยังไม่ปิด / ปิดแล้ว / รอลงนาม / มีของค้าง · ปุ่มค้าง, สแกน, ปิด, เปิดใหม่, รายงาน
      Export Excel / CSVส่งออกตามตัวกรองที่เลือก แยกตัวเลขรายประเภทครบทุกคอลัมน์
      การสแกนล่าสุดฟีดจากทุกเครื่องแบบ Real-time
      Auto-refresh 10 วินาทีหรือกด Sync ทันที เมื่อต้องการข้อมูลล่าสุด

      7 รายการสต๊อกทั้งหมด

      • แท็บ Onhand · OverStock (สต๊อกเกิน) · อุปกรณ์ติดตั้ง
      • กรองตามประเภท / สถานะ / แผนก / หน่วยรถ · ปุ่ม ยังไม่พบ แสดงเฉพาะรายการที่ยังไม่เจอ · ช่องค้นหา SN / ชื่อ / ทะเบียน
      • ปุ่ม Export Excel / CSV ส่งออกตามตัวกรองที่เลือก (เปิดใน Excel ภาษาไทยไม่เพี้ยน)

      8 สำหรับผู้ดูแลระบบ (Admin)

      อัปโหลดไฟล์ Onhand
      1. เมนู อัปโหลดไฟล์ Onhand → เลือกไฟล์ .xlsx (เลือกชีต “จัดไฟล์รวม” ให้อัตโนมัติ) หรือ .csv
      2. ตรวจตัวอย่างข้อมูลและจำนวน SN ซ้ำ
      3. กด อัปโหลดเข้า Google Sheets
      ติ๊ก “คงสถานะการนับเดิม” เมื่ออัปโหลดไฟล์ปรับปรุงระหว่างรอบ ผลการนับจะไม่หาย
      รอบการตรวจนับ
      1. เมนู รอบการตรวจนับ → ปิดรอบนี้ & เริ่มรอบใหม่
      2. ระบบสำรองข้อมูลรอบเดิมเป็นชีตซ่อน และบันทึกสรุปลงประวัติ
      3. เลือกล้าง Onhand เพื่ออัปโหลดไฟล์ใหม่ (แนะนำ) หรือใช้รายการเดิม
      ชื่อรอบตั้งให้อัตโนมัติ เช่น 2026-Q4 → 2027-Q1 (แก้ไขได้)
      เพิ่มผู้ใช้งาน ที่ชีต Users ใน Google Sheets: Username/Email · ชื่อ-สกุล · Role (Admin / Auditor) · สถานะ (Active / Inactive) · PIN

      9 ความหมายของสถานะ

      ยังไม่นับยังไม่ได้สแกน และคันยังไม่ปิด
      นับแล้วพบที่คันเจ้าของ
      พบต่างหน่วย (ยืม)พบที่คันอื่น — ไม่ถือว่าหาย
      ไม่พบปิดคันแล้วยังหาไม่เจอ — นับเป็นของหาย
      ไม่ได้นับปิดคันโดยไม่ได้ตรวจนับ มีเหตุผลกำกับ
      สต๊อกเกินพบของที่ไม่มีในไฟล์ Onhand

      10 แก้ปัญหาที่พบบ่อย

      เปิดกล้องไม่ได้
      มักเกิดจากเปิดลิงก์ในแอป LINE / Facebook → กด เปิดใน Chrome / Safari หรือใช้ปุ่ม ถ่ายภาพ สแกนแทน · ถ้าเคยกด “ไม่อนุญาต” ให้แตะไอคอนข้างช่องที่อยู่ → สิทธิ์ → กล้อง → อนุญาต แล้วรีเฟรช
      ไม่มีเสียงตอนสแกน
      แตะหน้าจอ 1 ครั้งก่อน (มือถือบล็อกเสียงจนกว่าจะมีการแตะ) · เพิ่มเสียงสื่อของมือถือ · ตรวจว่าสวิตช์ “เสียงสแกน” ในหน้าสแกนเปิดอยู่
      สแกนบาร์โค้ดยาก
